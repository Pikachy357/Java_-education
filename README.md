# Java_-education

Учебный репозиторий: решения алгоритмических задач на Java — Яндекс Контест, NeetCode / LeetCode и практические блоки по структурам данных.

## Стек

- Java 17+
- IntelliJ IDEA
- Без внешних библиотек, только стандартная библиотека Java

## Структура проекта

```
src/
├── contests/                 # Яндекс Контест
│   ├── c2026_03/             # контест, март 2026
│   ├── c2026_09_07/          # контест, 07.09.2026
│   ├── c2026_09_10/          # контест, 10.09.2026
│   ├── c2026_09_14/          # контест, 14.09.2026
│   └── c2026_09_16/          # контест, 16.09.2026
└── practice/                 # практика
    ├── basics/               # первые задачи и NeetCode (TwoSum, IsAnagram, TopKFrequent и др.)
    ├── block1/
    │   ├── stack/            # стек: проверка скобочной последовательности
    │   └── postfix/          # стек: вычисление постфиксной записи
    ├── block2/
    │   └── queue/            # очередь
    └── block3/
        └── quicksort/        # быстрая сортировка
```

Правила именования:

- пакеты — строчными буквами, без пробелов и дефисов;
- контесты — по дате: `cГГГГ_ММ_ДД`;
- классы — в CamelCase: `Task1`, `TwoSum`.

## Как запустить

**В IntelliJ IDEA:**

1. `File → Open` → папка репозитория.
2. Правый клик по `src` → `Mark Directory as → Sources Root`.
3. Открыть нужный класс и нажать ▶ рядом с методом `main`.

**Из командной строки** (из корня репозитория):

```bash
javac -d out src/contests/c2026_09_07/Task1.java
java -cp out contests.c2026_09_07.Task1
```

Большинство решений читают входные данные из стандартного ввода (`System.in`), как того требует Яндекс Контест.
